\# Smart Inventory \& Demand Prediction



A full-stack inventory management application built with Java, Spring Boot, React, and PostgreSQL. The application helps manage products and sales while providing inventory insights and demand prediction.



\## Features



\- User registration and login

\- JWT-based authentication

\- Product management

\- Sales recording

\- Automatic stock updates after sales

\- Inventory dashboard

\- Low-stock monitoring

\- Demand prediction based on historical sales

\- Reorder point calculation

\- AI-powered inventory advice using Ollama

\- PostgreSQL database

\- REST APIs

\- Docker support for the backend
